# مَركز | إدارة السنتر التعليمي

تطبيق عربي RTL لإدارة المدرسين والمجموعات والطلاب والحضور، مع صفحة مستقلة لكل مدرس ورفع صورة شخصية له. الواجهة مبنية بـ React وVite داخل `frontend/`، وواجهة API بـ Express داخل `backend/`، والبيانات محفوظة في SQLite داخل `data/center.sqlite`.

## بنية المشروع

- `frontend/src/components/`: المكونات المشتركة.
- `frontend/src/pages/`: صفحات التطبيق.
- `frontend/src/services/` و`frontend/src/utils/`: الاتصال بالـAPI والدوال المساعدة.
- `backend/routes/` و`backend/middleware/`: مسارات API والتحقق من الصلاحيات.
- `backend/config/` و`backend/services/`: تهيئة قاعدة البيانات والخدمات المشتركة.
- `backend/app.js`: نقطة تشغيل الخادم.
- `package.json` في الجذر: أوامر التشغيل والبناء لمساحتي العمل.

## التشغيل المحلي

```powershell
npm.cmd install
npm.cmd run dev
```

افتح `http://localhost:5173`. في أول تشغيل محلي، تُنشأ بيانات تجريبية تلقائيًا:

- المدير: `admin` / `markaz123`

## البيانات والصلاحيات

تظل البيانات بعد إغلاق التطبيق في ملف SQLite. تسجيل الدخول مخصص لمدير السنتر؛ لا توجد حسابات دخول للمدرسين ولا يمكنهم فتح كشف الطلاب. الحضور محفوظ لكل مجموعة وتاريخ، والطالب يمكن تسجيله في أكثر من مجموعة. الحذف نهائي: حذف الطالب يمسح تسجيلاته وحضوره، وحذف المدرس يمسح مجموعاته وحضورها؛ كما تُحذف بيانات الطلاب المرتبطين به وحده، بينما يبقى الطالب المسجل لدى مدرس آخر.

## استيراد الطلاب من Excel

من صفحة الطلاب، اختر **استيراد طلاب**، وحدد المجموعة ثم ملف `.xlsx` أو `.xls` لمعاينة السجلات قبل تأكيدها. يتوفر الزر أيضًا في قسم طلاب المجموعة داخل ملف المدرس، ويقصر اختيار المجموعات هناك على مجموعات ذلك المدرس. يدعم الاستيراد أعمدة اسم الطالب ورقم الهاتف وهاتف ولي الأمر والصف الدراسي والملاحظات؛ الاسم مطلوب، أما بقية الأعمدة فاختيارية. تُتجاهل الصفوف الفارغة، وتُعرض السجلات غير الصالحة والمكررة للمراجعة. الحد الأقصى 500 طالب في الدفعة، ويضيف الخادم الطلاب وتسجيلاتهم في SQLite ضمن معاملة واحدة.

## تشغيل الإنتاج

انسخ `.env.example` إلى `.env` قبل أول تشغيل، وغيّر `JWT_SECRET` و`ADMIN_PASSWORD` إلى قيم قوية وفريدة. في وضع `NODE_ENV=production` لا تُنشأ الحسابات أو البيانات التجريبية، ويلزم تعيين سر JWT وكلمة مرور المدير قبل تهيئة قاعدة البيانات. شغّل `npm.cmd run build` ثم `npm.cmd start`.

هذا الإصدار مُجهز للتشغيل على جهاز واحد أو شبكة داخلية. إتاحته عبر الإنترنت لعدة فروع تحتاج نشرًا على خادم آمن، ونسخًا احتياطيًا دوريًا لقاعدة البيانات، وإعداد HTTPS.
